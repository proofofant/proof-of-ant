# Proof of Ant: frontend

Next.js 16 app: browser miner (Web Workers), live colony map, rewards, leaderboard and the
`/api/rpc` proxy. See the [root README](../README.md) for setup.

```bash
npm install
npm run dev     # http://localhost:3000, reads .env.local (written by `npm run local:setup`)
npm run build && npm start
```
